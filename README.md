# cherry-lime-theme
VS Code theme blending cherry red and lime green for a stylish coding experience.

# Quickest way to open it

Press Win + R.
Paste %USERPROFILE%\.vscode\extensions and press Enter.
File Explorer opens that folder directly.

Copy the unzipped cherry-lime folder in there, then restart VS Code.

If you don’t see it: .vscode is a hidden folder, so it won’t show up when you browse normally, but the Win + R method works anyway. If Explorer says the folder doesn’t exist, open VS Code once and install any extension, which creates it.

If you use macOS or Linux: the folder is ~/.vscode/extensions. In a terminal, run open ~/.vscode/extensions on Mac or xdg-open ~/.vscode/extensions on Linux
